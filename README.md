# ICA Unified

Unified LMS + AMS business management platform by I Computer Anything.

The web workspace combines learning, workforce administration, credentials, CE/compliance, documents, workflows and organization integrations. Customer memberships and ICA platform administration use separate sign-ins and permissions.

- [Customer and administrator guide](docs/UNIFIED_DIRECTIONS.md): current navigation, invitations, learning, integrations, account deletion and completion review.
- [Developer guide](https://unified.icomputeranything.com/developers): API keys, member endpoints and signed webhook delivery/recovery.
- [Cloudflare operations](docs/CLOUDFLARE.md): deployed architecture and release checks.
- [Launch QC and remaining gates](docs/CUSTOMER_LAUNCH_QC.md).
- [Mobile setup](mobile/README.md) and [native release readiness](mobile/RELEASE_READINESS.md).
- [Desktop packaging](desktop/README.md).
